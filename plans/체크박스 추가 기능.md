# 그리드 좌측 체크박스 추가 기능 계획

## 목표

`HGrid` 컴포넌트에 `enableRowSelection: boolean` 타입의 파라미터를 추가하여, 이 파라미터가 `true`일 경우 그리드 각 행의 가장 좌측에 체크박스 컬럼을 렌더링하도록 합니다. 이 체크박스를 통해 행 선택 기능을 제공합니다.

## 영향을 받는 파일

- `grid/src/HGrid.tsx`
- `grid/src/types.ts`
- `grid/src/styles/grid.css`

## 구현 단계

1. `HGrid` 컴포넌트에 `enableRowSelection` 파라미터 추가
2. `enableRowSelection`이 `true`일 때, 체크박스 컬럼 렌더링 로직 구현
3. 체크박스 상태 관리 및 선택된 행 데이터 반환 기능 구현

## 고려 사항

1. 체크박스 컬럼이 추가될 때 기존 컬럼과의 레이아웃 조정 필요
2. 선택된 행 데이터 관리 및 외부로 반환하는 방식 설계
3. 체크박스 컬럼의 스타일링 및 접근성 고려
4. `enableRowSelection`이 `false`||`undefined`일 때 기존 그리드 기능이 정상적으로 작동하는지 확인
5. 체크박스 컬럼이 추가된 경우, 그리드의 성능에 미치는 영향 평가 및 최적화 필요
6. 기존 드래그 기능과 체크박스 컬럼이 충돌하지 않도록 구현
